# Security policy

FileGate is pre-release software. There are no supported production releases yet.
The declared inspection coverage and remaining containment work are documented in
[the roadmap](docs/roadmap.md) and [image profile](docs/image-profile.md).

## Reporting a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/alby-raju/filegate/security/advisories/new)
for vulnerabilities. Include the affected revision, platform, minimal reproduction,
expected behavior and observed impact. Remove credentials and personal data from
logs and sample files; describe sensitive reproductions before attaching them.

Keep vulnerability details in the private report while maintainers investigate.
Ordinary build failures and feature requests can use public issues. A report does
not imply a guaranteed response deadline or a production support commitment.
